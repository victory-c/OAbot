Recruiting emails come in. You just show up.

Students miss online assessments and walk into interviews unprepared, not because they can't do them, but because deciding when costs energy they don't have. Hire Me Maybe watches your inbox, blocks the time and writes the prep.

Run it in 2 minutes View the code

What it does

Claude reads each email and decides what kind it is. Everything else is ignored.

OA invite

Blocks the best slot

Reads the deadline, checks your calendar and bCourses workload, and books a slot with the test link and a prep tip inside the event.

Interview confirmed

Writes the prep doc

Researches the company and interviewer on the web, reads your resume, writes a sourced prep doc and blocks a prep session right before.

"Send your availability"

Drafts the reply

Picks three times that fit your week and drafts the reply. It never sends email. You do.

Every block shows its reasoning

Claude proposes a slot, then code checks it is really free. If Claude picks something that overlaps a class, code rejects it and falls back to the earliest free slot.

  • Weighs classes, exams and bCourses deadlines against the OA deadline
  • A second email about the same OA shows as a quiet Reminder, not a double booking
  • Handles the messy ones: deadlines in Eastern time, two-part OAs, rejections, job-board digests
OA invite · Stripe● Scheduled
Stripe OA (HackerRank, 90 min)Thu 2:00 – 3:30 PM · deadline Sat 11:59 PM

Why: Wednesday night is before your CS 161 midterm, and Friday afternoon has Homework 6 due at 7 PM. Thursday after lecture is open and leaves two days of buffer.

How it works

A FastAPI app on your laptop. Gmail is polled every 15 seconds; you can also paste an email in by hand.

Gmail poll (15s) ─┐
                  ├─> classifier.py ──> oa ─────────> scheduler.py ──> calendar block
Paste box ────────┘   (Claude: what       interview ─> researcher.py ─> prep doc
                       is this email?)                 scheduler.py ──> prep block / reply draft

Try it without Google

Mock mode uses a fake class schedule and bCourses deadlines and saves blocks locally. Everything Claude does is real.

Connect the real things

Gmail (read-only), Google Calendar, your bCourses calendar feed, your resume, and optional Discord pings.

Quiz me

Every prep doc can interview you in the interviewer's voice, so the first question isn't the first time you hear it.

Run it

Needs Python 3 and an Anthropic API key.

git clone https://github.com/victory-c/OAbot.git && cd OAbot
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env        # then put your ANTHROPIC_API_KEY in .env
uvicorn app.main:app --reload --port 8000

Open http://localhost:8000, open Paste an email, click a sample like oa, hit Process email.

Honest limits

  • Never sends email. Availability replies are drafts.
  • Runs on a laptop today, for one user.
  • Gmail access is read-only. Calendar access only ever creates new events.
  • Prep docs come from public web pages and can be wrong.
  • No rescheduling if you skip a block.
